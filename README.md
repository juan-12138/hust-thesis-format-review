# 华中科技大学硕士学位论文 Word 格式审查器

用于依据华中科技大学理工科硕士学位论文参考模板，审查 Word 论文的页面、页眉页脚、字体、段落、标题、摘要、目录、图表、公式、脚注和参考文献格式，并生成批注版论文及审查报告。

## 安装

```powershell
python "$env:CODEX_HOME\skills\.system\skill-installer\scripts\install-skill-from-github.py" --repo juan-12138/hust-thesis-format-review --path . --name hust-thesis-format-review
```
